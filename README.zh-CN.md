# 视频修复工具箱

[English](README.md) | [简体中文](README.zh-CN.md)

本地优先的视频修复与合并工具箱：先诊断、再确认、最后原地修复——你的视频文件不会离开本机。

## 它能做什么

MP4/MOV 文件损坏，通常是录制中断、存储卡非正常拔出或传输失败造成的。本工具先检查文件、告诉你实际问题所在，再按从轻到重的顺序尝试修复策略。只有修复结果通过校验后，原始文件才会被替换。

同一套服务也负责合并：逐个探测片段、展示每个片段的处理策略，并在确认产物无误后才把源文件移入废纸篓。

## 功能特性

- **诊断 → 确认 → 修复。** 诊断只读，不改动文件。写入之前你能看到问题和处置方案。
- **优先无损的修复链。** 依次尝试头部修复、索引重建、重封装、裸流恢复、重编码——能用的最轻手段优先。
- **不上传任何文件。** Node.js 服务只绑定 `127.0.0.1`，路径在运行服务的本机解析。
- **校验通过才原地替换。** 视频流、音轨和时长检查通过后才替换原文件。
- **合并前先出逐片段方案。** 执行前会标明每个片段是无损复制、重封装还是必须重编码。
- **合并队列与安全清理。** 每个产物单独校验，只有确认无误才把源文件移入废纸篓；单个任务失败不影响后续任务。
- **移入废纸篓，而非永久删除。** 删除接口只接受最近一次修复作业记录的路径。
- **深色 Web 界面**，支持 macOS 原生文件夹/文件选择器。

## 快速开始

### macOS（最省事）

双击 `启动视频修复.command`。脚本会检查依赖、启动本地服务，并在浏览器中打开界面。

### 手动启动

```bash
node server.mjs
```

然后打开 <http://127.0.0.1:8731>。端口可通过 `PORT` 修改：

```bash
PORT=9000 node server.mjs
```

关闭终端窗口或按 Ctrl+C 即可停止服务。

## 环境依赖

| 依赖 | 说明 |
| --- | --- |
| Node.js 20.11+ | 服务端使用了 `import.meta.dirname`。 |
| ffmpeg / ffprobe | 需在 `PATH` 中；启动脚本也会检查 `/opt/homebrew/bin`。 |
| untrunc（可选） | 用于 moov 索引重建。`vendor/untrunc` 内有现成程序或源码；编译出 `untrunc` / `untrunc-81`，或放到 `PATH` 中。 |
| macOS（可选） | 仅 `.command` 启动脚本和原生选择器/保存面板需要；Web 界面本身支持任意现代浏览器。 |

macOS 上用 Homebrew 安装：

```bash
brew install node ffmpeg
```

## 使用方法

### 修复

1. 添加文件、添加整个文件夹，或直接粘贴路径；支持 `file://` URL 和 `~`。
2. 点击**开始诊断**。这一步只读取文件，不做改动。
3. 查看结果，点击**确认修复**。界面会按策略显示进度。
4. 失败项可以重试；失败的源文件可以移入废纸篓——但只限于最近一次作业产生的路径。

同一设备录制的完好视频可以显著提高索引重建成功率，其编解码器、分辨率和帧率需与损坏文件一致。

### 合并

1. 逐个添加片段，或添加整个文件夹。
2. 点击**另存为**，在原生保存面板中选择输出位置。
3. 点击**开始合并**。方案会标明每个片段是无损复制、需要重封装，还是必须重编码。
4. 点击**在 Finder 中显示**定位产物。队列模式可连续执行多组合并，并在每组清理源文件前单独校验。

## 修复原理

策略按侵入性从低到高依次尝试：

1. **头部 / ftyp 修复** —— 当媒体数据和 moov 盒完好、仅开头头部被截断时进行补全，逐字节无损。
2. **untrunc 索引重建** —— 借助同设备录制的完好参考视频，重建缺失的 moov 盒。
3. **重封装** —— 只重建容器，不触碰基本码流。
4. **裸流恢复** —— 把媒体基本码流重新组装进新容器。
5. **重编码** —— 最后的手段，码流本身需要重建时才使用。

每次尝试后都会校验产物。只有视频流、音轨和时长都正常，修复结果才会被采纳；如果源文件时长未知，工具会明确提示无法确认完整性。

## 隐私与安全

- 服务只监听本地回环地址，不对外网开放。
- 视频字节不经过浏览器传输，服务端直接操作本机真实路径。
- 只有校验通过后才会原地替换文件。
- 删除操作走废纸篓；删除接口仅接受最近一次修复作业记录的路径，异常客户端无法把它当成任意文件删除接口。
- 跨卷移入废纸篓失败时，工具会给出具体原因并保留文件，不会静默丢失素材。

```text

lib/joblog.mjs          作业日志

启动视频修复.command      macOS 启动脚本
```

## 测试

```bash
node test/run-tests.mjs
```

## 已知限制

- 未编译 untrunc 时无法进行 moov 索引重建，其他策略不受影响。
- 源文件时长未知时，工具无法证明恢复完整；请自行核对时长，并保留备份。
- 跨卷移入废纸篓可能失败，工具会说明原因并保留文件。
- Web 界面目前仅有中文。
